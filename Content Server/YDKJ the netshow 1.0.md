# Content Server - YDKJ the netshow 1.0
All content that the netshow 1.0 engine asks for must be in the `jol` folder.
<br>Older versions of the engine uses a folder that has the engine's version - the only known one of these currently is `ver28`.
## `/jol/qfold/`
All the questions for the episodes are here, as well as the file that contains the information of the FP SRF files.
<br>They are seperated into folders with their episode numbers. (e.g. `/jol/qfold/e82/`)

## `/jol/adfold/`
The SRF files for the interstitial ads are found here.

## `/jol/fp/`
The additional audio SRF files are stored here.
<br>This uses a version folder, but it is completely different from the engine version.
<br>The only one currently known is `v12`. (e.g. `/jol/fp/v12/`)
