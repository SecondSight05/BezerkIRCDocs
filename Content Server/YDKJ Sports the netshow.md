# Content Server - YDKJ Sports the netshow
All content that the Sports Netshow engine asks for must be in a folder that has the engine's version.
<br>The only two currently known are `sver7` and `sver8`. (I will be using sverX below)
## `/sverX/`
Contains the extra audio SRF files, as well as the SRF file containing information about them.

## `/sverX/adfold/`
The SRF files for the interstitial ads are found here.

## `/sverX/qfold/`
All the questions for the current episode are stored here.
<br>Unlike the other netshows, Sports the netshow's Content Server can only store one episode.
