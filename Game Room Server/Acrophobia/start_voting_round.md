# `start_voting_round`
Used to start a Voting Round.
### Example use:
`start_voting_round 2500 45000 1`
<br>Details:
- 1: How long the animations take before the round starts.
- 2: How long the round timer will last in milliseconds.
  - There's always at least 20 seconds in a non-faceoff Voting Round.
  - Depending on the player count, it can go up to 45 seconds.
  - (I could be wrong about this, there aren't many sources...)
- 3: The round number.
