# `start_comp_round`
Used to start a Composition Round (The typing round).
### Example use:
`start_comp_round 2500 60000 1 "ACRO" "category"`
<br>Details:
- 1: How long the animations take before the round starts.
- 2: How long the round timer will last in milliseconds.
  - Non-faceoff Composition Rounds are always 60 seconds long.
  - Do not make this longer than 99 seconds.
- 3: The round number.
- 4: The Acro of the round.
  - This must be in ALL CAPS, and only letters.
- 5: The category of the Acro.
